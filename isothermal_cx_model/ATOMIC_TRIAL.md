# Атомная модель: этап 1 включения ионизации

Описание границ первого коммита. Этап 2 уже подключает процесс к локальному
стационарному поиску: см. ATOMIC_STATIONARY.md. Пробный API ниже сохраняется.

Граница этого изменения: коэффициенты и пробный IVP при заданных theta,j_t,
профили и невязки. Автоматический поиск ионизующих стационарных решений в этот
этап НЕ входит. Это самостоятельная порция изменений для одного коммита.

## Имена и совместимость

Единственная реализация - `solver_atomic.py`: CX, возбуждение, Case A RR,
опциональная прямая ионизация атомов. Старый `solver_recombination.py` содержит
только переэкспорт solve_trial, без второй версии уравнений. Внутренние клиенты
переведены на новое имя. Старые внешние импорты продолжают работать.
Никакие другие исторические решатели не удаляются на этом этапе.

Выходная метка model теперь atomic_trial. Старый восстановитель профилей,
предполагающий J=J0, явно отвергает как atomic_trial, так и старый rr_trial.
Проверки балансов также находятся в solver_atomic и переэкспортируются
стационарным RR-решателем; нет двух разных формул балансов.

## Физика и API

Сохраняются T_i=T_e=const, заданные источник и кинетическая граница, холодные
покоящиеся атомы и постоянный заданный n0 на один расчёт. Ионизация и RR не
изменяют нейтральный фон. Произвольный n0(z) в этом этапе не добавляется.
Молекулы, трёхчастичная рекомбинация и новые уравнения температуры не добавлены.

```python
from isothermal_cx_model.ionization import make_ionization_coefficients
from isothermal_cx_model.solver_atomic import solve_trial, balance_checks

ion = make_ionization_coefficients(p, scale=1)
state = solve_trial(theta, j_target, p['beta'], D, p['lambda_sh'], geometry,
    E_exc=E_exc, rr=rr, ionization=ion, inlet_momentum=inlet)
if state['status'] == 'energy_matched':
    errors = balance_checks(state, p['beta'])
```

Переменные p,D,E_exc,rr,geometry,inlet создаются прежними фабриками.
Новый необязательный аргумент ionization принимает пару (D_ion,E_ion) или
функцию theta -> эта пара. Он по умолчанию (0,0), то есть прежняя физика.
Пары численных констант пригодны для аналитических тестов; физическую связь
E_ion=(I/T_star)*D_ion обеспечивает фабрика, а не независимая настройка каналов.
Оба коэффициента вычисляются один раз за изотермический пробный расчёт.

    D_ion(theta) = eta*L*n0*k_ion(theta*T_star_eV)/u_star
    E_ion(theta) = (I_erg/T_star_erg)*D_ion(theta)

eta находится в [0,1]; n0 можно переопределить тем же значением, что у CX
и возбуждения. Масштабы и n0 скопированы фабрикой. При eta=0 и при n0=0
интеграл по электронному распределению не вызывается.

## Изменения уравнений

Как и прежде, фактическое интегрирование идёт по g=z/L назад от g=1.
xi=(g-alpha)/(1-alpha) возвращается в массивах на [0,1]. Переписывание самого
интегратора на xi не требуется для включения этого процесса.

    Delta = sqrt(mu^2-b^2*j^2), H=mu+Delta, b=sqrt(8*beta*theta)
    A = A(z)/A_star, Phi=H^2/(16*beta^2*theta^2*A)

    j_g = D_ion*H/(4*beta*theta) - R*Phi
    mu_g = -(H/2)*(ln B)_g - D*j - R*j*H/(4*beta*theta*A)
    omega_g = -D*(5*mu+Delta)/(8*beta)
              -(E_exc+E_ion)*H/(4*beta*theta)
              -R*j^2/(2*beta*A) -(1.5*R*theta+Q)*Phi

Прямого ионизационного источника полного импульса нет при u0=0.
В E_ion учитывается только энергия ионизации, без дополнительного 3T/2 или 5T.

Условия на приёмнике прежние: j=j_t, mu=b*j_t, omega=lambda*theta*j_t.
Вход находится по omega=1; затем вычисляются R_J=j_a-1 и R_M=mu_a-G(alpha).
energy_matched означает только найденную входную энергию, не полное решение.

Новые правила пробного IVP:

- j_t>1 разрешён. Универсального ограничения j_t<=1 больше нет.
- Требуется lambda*theta*j_t<1 и положительность j на всём профиле.
- При включённой ионизации j(z) может возрастать и менять монотонность.
- При выключенной ионизации сохраняется проверка неувеличения j.
- Для некритического дозвукового старта проверяется
  D+2*D_ion > -(b/2)*(ln B)_g_wall + R*b*j_t/(4*beta*theta*A_wall).
- Равенство остаётся critical_wall_unresolved. Возврат к звуку и достижение
  нулевого потока до входа остаются явными остановками, не ложными корнями.
- Положительный R_J и отрицательный целевой звуковой запас не обнуляют
  допустимую пробную невязку. Ни один из этих тестов не заменяет глобальный поиск.

Состояние содержит D_ion,E_ion и прежние массивы g,xi,j,mu,omega,N,v,A и Aq_e/W0.
balance_checks считает отдельно интегралы ионизации и RR. particle_loss_integral
для совместимости означает ТОЛЬКО число рекомбинаций, а не суммарное изменение J.
particle_net_source_integral - разность рождения и рекомбинации.
Ошибки particle_abs,momentum_abs,energy_abs нормированы на J0,M0,W0.
Малые ошибки балансов сами по себе не означают выполнения входных R_J=R_M=0.

## Пробный запуск

```powershell
python -B -m isothermal_cx_model.trial_atomic_example --temperature 3.272 --j-target 5 --density 1e15 --lambda-sh 7 --ionization-scale 1
```

Это намеренно ПРОБНЫЙ профиль, не готовое стационарное решение. В текущем
источнике он достигает входной энергии с ненулевыми R_J и R_M. Выводятся
коэффициенты, a, входные невязки и интегральные проверки. Никакие файлы
результатов или JSON не перезаписываются. Код 0 означает успешный IVP,
код 1 - явную остановку до согласования энергии, код 2 - ошибочные аргументы.

Повтор с --ionization-scale 0 отключает новый процесс. Есть настройки
--config, --cx-mode, --rr-scale, --excitation-scale, --geometry/--K,
--inlet-momentum и --points. Температура в эВ, n0 в см^-3.

## Проверки

```powershell
python -B -m unittest discover -s tests -p test_atomic_trial.py -v
```

Новые тесты проверяют фабрику и связь источников, прежний замороженный RR-профиль,
j_t>1, немонотонный j, звуковой старт, все размерные интегральные балансы,
численные ошибки и совместимость импортов. Для случая только с ионизацией
и постоянной площадью независимо проверяются mu=const и omega+epsilon*j=const,
а также два аналитически заданных решения всех ГУ и соответствующая alpha.
Это аналитические контрольные случаи, не автоматический поиск корней модели ГДЛ.
