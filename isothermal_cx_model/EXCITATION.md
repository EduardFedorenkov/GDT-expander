# Потери энергии на возбуждение атомов

Коэффициенты в excitation.py используются решателем transport.py, включая кинетическое входное
условие. Старые аналитические решатели `solver.py` и пакет `simple_cx_model`
не изменяются. Тормозное излучение, ионизация и рекомбинация не добавляются.

## Физическое приближение

Сохраняются T_i=T_e=const, J=J_0, заданная постоянная плотность атомов n_0,
прежние уравнение импульса и все граничные условия. Добавляется только
P_exc = eta * n*n_0*L_exc(T). Масштаб eta находится между 0 и 1.

Используется водородная низкоплотностная аппроксимация как оценка для D:

    T_K = 11604.518121550082 * T_eV
    L_exc = 7.5e-19 * exp(-118348/T_K) / (1 + sqrt(T_K/1e5))

L_exc измеряется в эрг*см^3/с; L_exc(0)=0. Энергия возбуждения уже включена:
дополнительно умножать коэффициент на 10.2 эВ нельзя.

Источник: [Katz, Weinberg & Hernquist, таблица 1](https://arxiv.org/pdf/astro-ph/9509107).
Берётся только коэффициент процесса, не предположение ионизационного равновесия.
Предполагаются максвелловские электроны, атомы преимущественно в основном
состоянии и низкоплотностный радиационный распад. Не учитываются населённости
уровней, столкновительное гашение, поглощение/перенос излучения и обратный нагрев.
Это не точные атомные данные дейтерия и не полная столкновительно-излучательная
модель. Для окончательного физического вывода потребуется проверка этих допущений.

## Безразмерная запись и координата кода

    beta = T_star_erg/(m_D*u_star**2)
    D(theta) = L*n_0*k_cx(theta*T_star_eV)/u_star
    E_exc(theta) = eta*L*n_0*L_exc(theta*T_star_eV)/(u_star*T_star_erg)
    Delta = sqrt(mu**2 - 8*beta*theta)
    H = mu + Delta

При g=z/L:

    dmu/dg    = -0.5*(d ln B/dg)*H - D
    domega/dg = -D*(5*mu + Delta)/(8*beta) - E_exc*H/(4*beta*theta)

Именно по g интегрирует код. Множитель (1-alpha) появляется ТОЛЬКО при записи
производной по xi=(g-alpha)/(1-alpha); внутри rhs(g, state) его добавлять нельзя.
Явной площади в возбуждении нет: A*n*n_0*L_exc = J_0*n_0*L_exc/u.

Алгоритм прежний: от звуковой стенки интегрируем до omega=1, затем подбираем
theta по входной невязке импульса. При проверке корня и восстановлении графиков
сохраняется то же E_exc, что использовалось в поиске.

Случай D=0 по-прежнему не реализован; при ненулевом возбуждении он явно
помечается как неподдерживаемый, а не обрабатывается формулой для CX-only.

## Запуск из корня проекта

Актуальный решатель включает также RR и ионизацию.
Для исследования только CX + возбуждения задайте --rr-scale 0 --ionization-scale 0.
Начальный старт в локальном решателе не гарантирует сходимость.

```powershell
python -B -m isothermal_cx_model.scan_stationary --excitation-scale 0.25 --rr-scale 0 --ionization-scale 0 --no-show --output excitation_check
python -B -m isothermal_cx_model.scan_lambda --lambdas 8 --densities 1e14 --excitation-scale 1 --rr-scale 0 --ionization-scale 0 --no-show --output excitation_scan
```

Для каждого расчёта выбирайте новую папку --output.
D(theta) и E_exc(theta) используют одну и ту же заданную плотность нейтралов.
