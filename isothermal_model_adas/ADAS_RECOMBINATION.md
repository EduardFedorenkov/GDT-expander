# Коэффициенты ADAS ACD12/PRB12: отдельный модуль

`recombination_adas.py` НЕ заменяет `recombination.py` автоматически и пока
не подключён к `transport.py`, стационарному поиску или сканам.
Существующая физика и результаты не меняются.

## Что возвращается

```python
from isothermal_cx_model.recombination_adas import (
    adas_coefficients, alpha_adas, C_eff, L_gamma_adas,
)

alpha, cooling = adas_coefficients(T_eV=1.0, n_e_cm3=1e13)
photons = L_gamma_adas(T_eV=1.0, n_e_cm3=1e13)
```

- `alpha`: ACD, см³/с.
- `photons`: `1e7 * PRB`, эрг·см³/с (в исходном файле Вт·см³).
- `cooling`: `C_eff = 1e7*PRB - I_D*ACD`, эрг·см³/с,
  где I_D=13.6 эВ с переводом в эрги.

Вклад нового канала в размерные потери W:

```text
n_e*n_i * [alpha*(m_D*u²/2 + 3*T_i/2) + C_eff]
```

T_i здесь в эргах. W не включает энергию ионизации.
PRB уже содержит тормозное излучение. Его нельзя добавлять повторно.
Отрицательный C_eff сохраняется; это не отрицательная фотонная мощность.
C_eff/ACD нельзя интерпретировать как среднюю кинетическую энергию
захватываемого электрона: коэффициент содержит более общую физику и PRB.

Скаляры возвращают float. Массивы NumPy допускаются и согласуются по
broadcasting. Плотность на входе — ЭЛЕКТРОННАЯ, не плотность нейтралов n0.

## Безразмерная фабрика

```python
from simple_cx_model.config import load_cx_config
from isothermal_cx_model.recombination_adas import make_adas_coefficients

p = load_cx_config('simple_cx_model/cx_config.json')
coefficients = make_adas_coefficients(p, scale=1.0)
R_A, Q_eff = coefficients(theta=1.0/p['T_star_eV'], N=1e13/p['n_star_cm3'])
```

`N=n_e/n_star`. Вычисляются
`R_A=L*n_star*ACD/u_star`,
`Q_eff=L*n_star*C_eff/(u_star*T_star_erg)`.
Масштабы копируются при создании фабрики; n0 не нужен.

Фабрика возвращает функцию ДВУХ аргументов, а не прежнюю `theta -> (R,Q)`.
Её нельзя просто передать существующему параметру `rr` решателя.
Нужно будет отдельно реализовать локальное вычисление плотности и пересмотреть
ограничение Q>=0 и, если появляется суммарный нагрев, монотонность W.

`scale=0` (по умолчанию, как у старой фабрики) возвращает `(0,0)`, не читая
файлы или параметры. При включении scale умножает ВЕСЬ канал ACD/PRB,
в том числе тормозное излучение, а не исключительно рекомбинацию.

## Таблицы и интерполяция

По умолчанию файлы ищутся относительно модуля в `processes_data/`:
`acd12_h.dat`, `prb12_h.dat`. Это уже скачанные водородные данные ADAS;
они используются приближённо для D, а не выдаются за отдельный D-набор.
Водородный одноблочный формат проверяется; это не универсальный ADF11-парсер.

Применена билинейная интерполяция log10(ACD), log10(PRB) по
log10(T_e), log10(n_e). C_eff вычисляется ПОСЛЕ интерполяции положительных
коэффициентов; логарифм отрицательной разности не берётся.
Это явно выбранное первое приближение, не точное воспроизведение сплайнов ADAS.

Диапазоны: T_e=0.2–1e4 эВ, n_e=5e7–2e15 см^-3.
За пределами выдаётся `ADASDomainError`, без экстраполяции и без физического
температурного/плотностного пола. Допуск 1e-8 в логарифме используется только
у границ: например, напечатанное log10(T_min)=-0.69897 немного отличается
от log10(0.2). Точки в этом допуске привязываются к граничному узлу.
Ноль, отрицательные значения и NaN не допускаются.

Таблицы загружаются лениво один раз на процесс. После замены файлов
перезапустите Python либо явно создайте новый объект
`ADASRecombination(acd_path, prb_path)` и передайте его как `data=...`.
Исходные .dat файлы и их условия использования не изменяются и не включаются
в патч/архив кода.

## Контрольный запуск и тесты

```powershell
python -B -m isothermal_cx_model.recombination_adas --density 2e15 --temperatures .2 1 5 20
python -B -m unittest discover -s tests -p test_recombination_adas.py -v
```

При .2 эВ и 2e15 см^-3: alpha=3.293441851e-9 см³/с,
PRB_CGS=5.217830896e-20 и C_eff=-1.958447893e-20 эрг·см³/с.
Синтетические тесты работают без внешних данных. Проверки настоящих узлов и
CLI пропускаются, если пользователь не скачал локальные файлы ADAS.
