# Потери на возбуждение по PLT12_H

Модуль назван **exitation_adas.py**, точно как в запросе пользователя.
Это слой коэффициентов, пока НЕ подключённый к sources/transport/балансам.
Существующие уравнения, настройки запуска и старый пакет не изменяются.

## Размерный коэффициент

```python
from isothermal_model_adas.exitation_adas import L_exc

Lambda_PLT = L_exc(T_eV=10., n_e_cm3=1e13)  # erg cm^3/s
```

    Lambda_PLT(T,n_e) = 1e7*PLT(T,n_e)
    P_exc = n_e*n0*Lambda_PLT

Сама таблица содержит W cm^3. Ровно один множитель 1e7 переводит в СГС.
Энергия фотонов уже включена: **не умножать на I или энергию возбуждения**.
PLT заменяет прежнюю аппроксимацию L_exc, а не суммируется с ней.
I*SCD и PRB остаются отдельными каналами. При W без энергии связи
нейтрально-обусловленная часть потерь будет n_e*n0*(I*SCD+Lambda_PLT).

В отличие от старого L_exc(T), здесь **обязателен аргумент n_e**.
Это локальная электронная плотность, не нейтральная n0.
PLT — эффективный CR-коэффициент линейчатой мощности, а не один переход.
Используются H-данные как приближение для дейтерия. Максвелловские электроны,
локальная CR-редукция населённостей и уход энергии фотонов остаются допущениями;
перенос/переабсорбцию излучения этот модуль не решает.

## Безразмерный коэффициент

```python
from isothermal_model_adas.exitation_adas import E_exc, make_E_exc

E = E_exc(theta, N, p)                  # N=n_e/n_star
E_of_state = make_E_exc(p, scale=1.0)
E = E_of_state(theta, N)                # будущий локальный вызов внутри RHS
```

    E(theta,N) = scale*L*n0/(u_star*T_star_erg)
                 *Lambda_PLT(theta*T_star_eV,N*n_star)

Нормировка требует L_cm, U_star_cm_per_s, n_star_cm3, T_star_eV, T_star_erg.
Две формы T_star проверяются на согласованность. n_star входит только в
аргумент электронной плотности, а **не** дополнительным множителем в E.
Нейтральная плотность задаётся через p['n0_cm3'] либо аргумент:

```python
E_of_state = make_E_exc(p, n0_cm3=1e14, scale=1.0)
```

Порядок аргументов фабрики сохранён от старого make_E_exc(p,n0_cm3,scale).
Но возвращаемая функция имеет **два аргумента**, theta,N. Одноразовый E_exc
также явно принимает N: его сигнатура теперь E_exc(theta,N,p,...).

scale по умолчанию 0, как в прежнем модуле: возвращает число 0. без чтения
файлов и параметров. При n0=0 также возвращается 0. без загрузки данных.
Включённая фабрика фиксирует исходные масштабы и n0; последующее изменение
словаря p не меняет её поведение. Скаляры и broadcasting массивов поддержаны.

После будущего подключения изменится только энергетическая правая часть:

    omega_xi,exc = -(1-alpha)*E(theta,N)*A_ratio*N
    j_xi,exc = mu_xi,exc = 0

## Чтение таблицы и ошибки

```python
from isothermal_model_adas.exitation_adas import ADASExcitation
tables = ADASExcitation(path)
Lambda_PLT = L_exc(10., 1e13, data=tables)
```

По умолчанию читается processes_data/plt12_h.dat. Reader специализирован
для единственного блока водорода **IPRT=1, IGRD=0, Z1=1**. Ноль не заменяется
единицей и не трактуется как отсутствие потерь. Это проверка структуры именно
данного файла; не универсальное правило для всех PLT-наборов ADAS.
Проверяются единицы мощности, число значений, порядок осей и конечность данных.
Ошибки формата — общий ADASDataError; отсутствие файла — обычный OSError.

Линейная интерполяция в log10(T),log10(n_e),log10(PLT), как в ACD/SCD/PRB.
Это выбранная оценочная схема, не воспроизведение ADAS-сплайнов.
Диапазон текущего файла: 0.2–10000 eV и 5e7–2e15 cm^-3. Вне его — общий
ADASDomainError, без экстраполяции или физических полов. Допуск 1e-8 по
логарифмическим концам учитывает лишь их округление в файле.
По умолчанию данные лениво кэшируются; при замене .dat перезапустить Python
либо создать новый объект ADASExcitation.

Источник: https://open.adas.ac.uk/element/detail/adf11/plt12/plt12_h.dat .
Сырой .dat уже находится у пользователя и не включается в патч.

Вывод коэффициентов без плазменного решателя:

```powershell
python -B -m isothermal_model_adas.exitation_adas --temperatures .2 1 5 20 100 --density 1e13
```

Здесь --density означает электронную плотность. В run_stationary одноимённый
аргумент задаёт нейтральную n0; не путать эти два назначения.

Тесты только коэффициентов:

```powershell
python -B -m unittest discover -s isothermal_model_adas/tests -p test_exitation_adas.py -v
```
