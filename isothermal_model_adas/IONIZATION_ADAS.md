# Ионизация по SCD12_H

`ionization_adas.py` — слой коэффициентов, **подключённый** к правой части,
проверке стенки, независимым балансам и стационарному API новой модели.
Старый пакет isothermal_cx_model не изменяется. Подключение проверено
алгебраически и с заглушками; реальные плазменные IVP/BVP не запускались.

## Размерный интерфейс

```python
from isothermal_model_adas.ionization_adas import (
    k_ion, L_ion, log_k_ion, ionization_coefficients,
    make_ionization_coefficients,
)

k = k_ion(T_e_eV=5.0, n_e_cm3=1e13)  # SCD, cm^3/s
L = L_ion(5.0, 1e13)                # I*SCD, erg cm^3/s
k, L = ionization_coefficients(5.0, 1e13)
ln_k = log_k_ion(5.0, 1e13)         # натуральный логарифм численного k в CGS
```

По смыслу это аналог прежнего `ionization.py`, но **электронная плотность —
обязательный дополнительный аргумент**. Это не нейтральная n0. SCD эффективный
CR-коэффициент, а не только прямая ионизация 1s. Водород приближённо описывает
дейтерий. Функции сечения sigma_ion_D нет: сечение не восстанавливается
непосредственно из этой двумерной тепловой таблицы.

`L_ion=I*SCD`, I=13.6 eV переведено в эрги. Это химическая часть энергетического
баланса при W без энергии связи; **не полные электронные потери энергии**.
Линейчатое излучение требует отдельного PLT, которого в этом модуле нет.
Дополнительные 3T/2, 5T или условные 30 eV на акт здесь не добавляются.
I*SCD согласовано с обратной поправкой -I*ACD внутри нашего C_eff.

## Безразмерный интерфейс

```python
coefficients = make_ionization_coefficients(p, scale=1.0)
D_ion, E_ion = coefficients(theta, N)  # N=n_e/n_star
```

    D_ion(theta,N) = scale*L*n0/u_star * SCD(theta*T_star_eV,N*n_star)
    E_ion(theta,N) = (I/T_star_erg)*D_ion(theta,N)

Требуемые положительные масштабы p: `L_cm`, `U_star_cm_per_s`, `n_star_cm3`,
`T_star_eV`, `T_star_erg`. Две единицы T_star должны быть согласованы.
Нейтральная плотность — поле `n0_cm3`, либо явный аргумент:

```python
coefficients = make_ionization_coefficients(p, scale=1., n0_cm3=1e14)
```

По умолчанию `scale=0`, как в прежнем модуле и фабрике рекомбинации.
При scale=0 возвращается `(0.,0.)` без параметров и чтения файла.
При n0=0 также возвращается `(0.,0.)` без загрузки таблицы.
scale между 0 и 1 одновременно умножает рождение частиц и энергетический
расход. Фабрика фиксирует значения масштабов и n0 при создании; изменение
словаря p после этого не меняет созданную функцию.

ВНИМАНИЕ: новый callback имеет **два аргумента**, а не только theta.
Он вызывается на каждом локальном RHS,
даже если температура постоянна. N и theta могут быть скалярами или
взаимно совместимыми для broadcasting массивами.

Реализованные источники:

    j_g,ion = D_ion*A_ratio*N
    mu_g,ion = 0
    omega_g,ion = -E_ion*A_ratio*N

Префактор D_ion содержит **n0**, не n_star. n_star используется только для
получения аргумента n_e; второй множитель n_e появится в самом источнике.
Для xi=(z-a)/(L-a) источники умножаются на 1-alpha.

## Подключение к модели

```python
from isothermal_model_adas.cx_adas import make_D
from isothermal_model_adas.transport import solve_trial, balance_checks

ion = make_ionization_coefficients(p, scale=1.)
# Пробное интегрирование: коэффициенты вычисляются локально внутри RHS.
trial = solve_trial(theta, j_t, alpha, p['beta'], p['lambda_sh'], recombination,
                    geometry, D=make_D(p), ionization=ion)
# Независимые балансы: необходимо передать тот же локальный provider.
budgets = balance_checks(trial, recombination, ion)
```

В solve_stationary также есть ionization=(0.,0.) по умолчанию для совместимости.
В CLI run_stationary, напротив, --ionization-scale=1 по умолчанию включает SCD.
--ionization-scale 0 возвращает версию с ACD/PRB и CX, без чтения SCD.
--density 0 выключает и CX, и ионизацию. --scale остаётся множителем ACD/PRB,
а не общим выключателем всех процессов.

Граничные условия не меняются. Проверка на стенке учитывает локальную SCD:

    F_g(1)/j_t = (b/2)*(ln A)_g(1)-D_cx-2*D_ion,t+R_t*N_t

Поиск больше не ограничивает j_t единицей; явные --j-min/--j-max задают только
численное окно. Рост J вдоль слоя допускается при ненулевой ионизации.
В NPZ сохраняются массивы D_ion и E_ion, в JSON schema_version=3 — множитель
ионизации, SHA256 активного scd12_h.dat, рождение частиц и расход энергии
в составе независимых балансов. Никакой замены профилей константами нет.

balance_checks с активной ионизацией требует provider третьим аргументом.
При его пропуске, если профиль содержит активную ионизацию, возвращается
явная ошибка, а не баланс с незаметно пропущенными источниками.

## Таблица, интерполяция, ошибки

Файл по умолчанию — `processes_data/scd12_h.dat`, уже добавленный пользователем.
Модуль не скачивает и не модифицирует данные. Для другого пути:

```python
from isothermal_model_adas.ionization_adas import ADASIonization
tables = ADASIonization(path)
k = k_ion(5.0, 1e13, data=tables)
```

Проверяются HYDROGEN, единственный блок IPRT=IGRD=Z1=1, размерности сеток,
порядок осей, конечность значений, единицы cm^3/s. ADF11 не содержит надёжного
признака SCD в самом числовом заголовке: пользователь отвечает за выбор именно
SCD, а не ACD с такой же формой и единицами.

Интерполяция линейна по log10(T),log10(n_e),log10(SCD), как для ACD/PRB.
Это выбранное первое приближение, не точное воспроизведение ADAS-сплайнов.
Диапазон текущего файла: 0.2–10000 eV, 5e7–2e15 cm^-3. Выход за него даёт
общий ADASDomainError. Нули/NaN/отрицательные значения — ValueError.
Никаких экстраполяций, температурных полов и искусственного обнуления ионизации.
Допуск 1e-8 в log10 учитывает только округление напечатанных концов сетки.
Данные лениво кэшируются на процесс; после замены .dat перезапустить Python
либо явно создать новый объект ADASIonization.

Источники: https://open.adas.ac.uk/element/detail/adf11/scd12/scd12_h.dat
и https://www.adas.ac.uk/notes/adas_c13-01.pdf . Исходный .dat не входит в патч.

Только вывод коэффициентов (НЕ запуск плазменного решателя):

```powershell
python -B -m isothermal_model_adas.ionization_adas --temperatures .2 1 5 20 100 --density 1e13
```

`--density` здесь электронная плотность, в отличие от одноимённого аргумента
плазменного run_stationary, где он задаёт нейтральную n0.

Тесты только коэффициентов:

```powershell
python -B -m unittest discover -s isothermal_model_adas/tests -p test_ionization_adas.py -v
```
