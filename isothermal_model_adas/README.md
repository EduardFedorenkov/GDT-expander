# Изотермическая модель с ACD/PRB

По умолчанию `--atomic-model hybrid`: только рекомбинационный канал использует
локальные таблицы ADAS ACD12/PRB12. Перезарядка, ионизация и потери на возбуждение
берутся из `isothermal_cx_model` и фиксируются на каждой пробной температуре.
Множители плотности в источниках не меняются. PRB уже содержит тормозное
излучение; отдельный тормозной член не добавляется.

`--atomic-model full-adas` сохраняет прежний вариант с CCD, SCD и PLT,
описанный ниже. В формулах для гибрида заменяются только CCD, SCD и
табличная мощность PLT на прежние (k_{cx}(T)), (k_{ion}(T)) и (L_{exc}(T))
соответственно. Модельный режим не меняет 3D-поиск по `(T,j_t,alpha)`.

Повторное построение T(n0), a(n0), j_t(n0) из CSV без запуска модели:
[PLOT_LAMBDA_RESULTS.md](PLOT_LAMBDA_RESULTS.md).

Пакетный перебор lambda_sh и n0 с сохранением CSV и продолжением по завершённым
парам: [SCAN_LAMBDA.md](SCAN_LAMBDA.md). Сначала используйте `--dry-run`:

```powershell
python -B -m isothermal_model_adas.scan_lambda --lambdas 8 --densities 1e13 --dry-run --no-show
```

Автоматическая карта и поиск без обязательного `--guess`:
[SCAN_STATIONARY.md](SCAN_STATIONARY.md). Без интегрирования и создания файлов:

```powershell
python -B -m isothermal_model_adas.scan_stationary --dry-run --no-show
```

Отдельный пакет, без импортов из `isothermal_cx_model` и `simple_cx_model`.
Старый решатель не изменяется. Проверены коэффициенты, алгебра источников и
передача параметров; вызовы интегратора/стационарного поиска в новых проверках
заменены заглушками. Физические IVP/BVP, поиск корней и сканы не запускались
по просьбе пользователя. Работа на физических профилях ещё не
верифицирована; наличие согласованных плазменных решений не утверждается.

## Физика и единицы

Стационарная квазинейтральная плазма дейтерия: `n_e=n_i=n`, `u_e=u_i=u`,
`T_e=T_i=T=const`. Вязкости нет. Температура в формулах энергии — в эргах,
в конфиге/ADAS — в eV. Потоки J,M,W интегрированы по магнитной трубке.

Первый атомарный канал — ACD/PRB. Он включает эффективную
рекомбинацию (ACD) и рекомбинационное плюс тормозное излучение (PRB). Поэтому
«только рекомбинация» здесь не означает исключение тормозного излучения из PRB.
Второй канал — перезарядка с k_model(T)=CCD96_D(T), при прежнем оценочном
замыкании переноса на холодных неподвижных нейтралах. Состав газа задаётся и постоянен
вдоль слоя; нейтралы не эволюционируют. Точное соответствие теплового усреднения
CCD этому замыканию ещё не установлено; это явное приближение.
Третий канал — эффективная ионизация SCD12_H(T_e,n_e) с затратами I*SCD.
Это CR-замыкание, не только прямая ионизация из 1s. Четвёртый канал — PLT12_H,
мощность возбуждённого линейчатого излучения. PLT заменяет прежнюю аппроксимацию
L_exc: старый коэффициент не добавляется. I*SCD и PLT — разные части потерь.
Примеси не учитываются.
Для ACD/PRB/SCD/PLT используются водородные данные как приближение для дейтерия;
CCD содержит массы дейтерия.

Для включения MAR/MAD/MAI в стационарном расчёте и сканах конфиг принимает
`molecular_fraction` (по умолчанию 0). Это доля молекул по числу нейтральных
частиц, не по числу ядер: `n_D2 = molecular_fraction*n0`,
`n_D = (1-molecular_fraction)*n0`. При первом приближении для AMJUEL
`n_D2(v=0) ≈ n_D2`. При изменении `n0_cm3` состав пересчитывается.
Например, `"n0_cm3": 1e13, "molecular_fraction": 0.3` задаёт
7e12 атомов и 3e12 молекул на см³. Флаг `--density` и сетка
`--densities` задают полную плотность `n0_cm3`, сохраняя эту долю.
Перезарядка с атомами, атомарная ионизация и PLT используют только `n_D`.
Для всех трёх молекулярных ветвей используется `n_D2` и водородные
аппроксимации AMJUEL H.4 как приближение для дейтерия. Явный температурный
диапазон этих аппроксимаций не указан; не следует считать низкотемпературную
экстраполяцию надёжно проверенной. Модельная энергия второго нейтрального
фрагмента MAD равна 2.9 эВ. Отчёты и пакетные CSV сохраняют состав газа.

Взяты прежние соглашения об энергии без энергии связи:

    J = A*n*u
    M = A*(m_D*n*u^2 + 2*n*T)
    W = J*(m_D*u^2/2 + 5*T) + A*q_e
    alpha_A(T,n) = ACD(T_eV,n)
    Lambda_B(T,n) = 1e7*PRB(T_eV,n)
    C_eff(T,n) = Lambda_B - I*alpha_A,  I=13.6 eV в эргах
    s(T,n) = SCD(T_eV,n_e)
    Lambda_PLT(T,n) = 1e7*PLT(T_eV,n_e)  [erg cm^3/s]

Уравнения:

    J_z = A*(n*n0*s - n^2*alpha_A)
    M_z = 2*n*T*A_z - A*m_D*u*(n*n0*k_cx + n^2*alpha_A)
    W_z = -A*{n*n0*k_cx*(m_D*u^2/2+3*T/2)
              + n*n0*(I*s+Lambda_PLT) + n^2*[alpha_A*(m_D*u^2/2+3*T/2) + C_eff]}
    T_z = 0

Отрицательный C_eff допустим. ACD/PRB интерполируются отдельно в логарифмах,
и лишь затем вычитается I*ACD. Положительная фотонная мощность не равна
непосредственно потере W. Отдельное тормозное излучение не добавляется.

`T=const` означает предел бесконечной теплопроводности, но **не** `q_e=0`:
конечный тепловой поток восстанавливается из W после решения.

## Обезразмеривание и ГУ

    u_* = M0/(m_D*J0), T_* = W0/J0
    n_* = J0/(A_m*u_*), beta = T_*/(m_D*u_*^2)
    j=J/J0, mu=M/M0, omega=W/W0, theta=T/T_*
    g=z/L, alpha=a/L, xi=(g-alpha)/(1-alpha)
    mathcal_A=A/A_m, b=sqrt(8*beta*theta)
    Delta=sqrt(mu^2-b^2*j^2), H=mu+Delta
    N=n/n_*=H/(4*beta*theta*mathcal_A), v=u/u_*=4*beta*theta*j/H
    R(theta,N) = L*n_*/u_* * ACD(theta*T_*,N*n_*)
    Q_eff(theta,N) = L*n_*/(u_* T_*) * C_eff(theta*T_*,N*n_*)
    D(theta) = L*n0/u_* * CCD(theta*T_star_eV)
    D_ion(theta,N) = L*n0/u_* * SCD(theta*T_star_eV,N*n_*)
    E_ion(theta,N) = (I/T_*)*D_ion(theta,N)
    E_exc(theta,N) = L*n0/(u_* T_*)*1e7*PLT(theta*T_star_eV,N*n_*)

Дозвуковая ветвь: mu>b*j внутри слоя, равенство на стенке. По g:

    j_g = D_ion*mathcal_A*N - R*mathcal_A*N^2
    mu_g = -(H/2)*(ln B)_g - D*j - R*j*N
    omega_g = -D*(5*mu+Delta)/(8*beta) - (E_ion+E_exc)*mathcal_A*N
              - mathcal_A*N^2*[R*(v^2/(2*beta)+1.5*theta)+Q_eff]

CX не входит в j_g: при D+ + D -> D + D+ число ионов не меняется.
Его энергетическая форма D*mathcal_A*N*(v^2/(2*beta)+1.5*theta) равна
D*(5*mu+Delta)/(8*beta). В независимых бюджетах используется первая форма.
R,Q_eff вычисляются локально по N; D(theta) — один раз на изотермический trial.
D_ion,E_ion также вычисляются ЛОКАЛЬНО по N, а не один раз по theta.
То же относится к E_exc: даже при постоянном T он зависит от локального N.
Нормировка PLT использует n0 в префакторе; n_star входит только в аргумент n_e.
Энергия фотонов уже есть в PLT: не умножать его дополнительно на I или 10.2 eV.
Холодные покоящиеся нейтралы дают нулевой источник консервативного импульса
при ионизации. Не добавлять -m*u*S_ion в M_z: массовая нагрузка уже учтена
через J_z. Не добавлять искусственные 3T/2 или 5T к I*SCD.

Для интегрирования по xi **вся** правая часть умножается на `(1-alpha)`.

    xi=0: j=1, mu=G(alpha), omega=1
    xi=1: mu=b*j_t, omega=lambda_sh*theta*j_t

Неизвестны theta, j_t, alpha. Постоянство theta реализовано параметром,
а не дополнительной ОДУ. G(alpha)=1 при постоянном входном импульсе, либо
прежняя кинетическая модель входа `M_kin(a)/M0` из `inlet.py`.

Кинетическая модель с chi — **унаследованное входное приближение**, а не часть
ADAS. Сохранена без физической переработки. В частности, n_m=n_c/2, T_m=T_c,
W0=chi_E*J0*T_c. Не следует заменять это умножением плотности на B_m/B_c.

## Допустимость дозвукового подхода к стенке

Пусть F=mu-b*j. На стенке:

    F_g(1)/j_t = (b/2)*(ln A)_g(1) - D - 2*D_ion,t + R_t*N_t

Для дозвукового слоя слева от стенки необходимо F_g(1)<=0. При D=D_ion=0,
расширении на стенке и ненулевой рекомбинации это невозможно. CX и ионизация
дают отрицательные -D и -2*D_ion,t: они могут снять локальное препятствие,
но это само по себе НЕ доказывает существование глобального решения.
Положительная производная даёт inadmissible_wall; нулевая в пределах численной
точности — critical_wall_unresolved (вырожденный случай пока не исследуется).

Геометрию нельзя менять на сужающуюся ради получения «решения для ГДЛ».
Сужающаяся геометрия в подготовленных тестах — исключительно контроль кода.
После добавления следующих процессов условие допустимости нужно обновлять.
PLT не даёт прямой добавки в F_g: он меняет только энергетическое уравнение,
но через искомую температуру может косвенно изменить допустимость решения.

## Файлы и стратегия

- `recombination_adas.py`: перенесённый пользователем reader/интерполятор;
  `make_adas_coefficients(p,scale=1)` возвращает функцию `(theta,N)->(R,Q_eff)`.
  Историческая пометка standalone в его docstring относится к старому пакету.
- `cx_adas.py`: k_cx(T), D_cx(theta,p), make_D(p); только CCD96_D(T).
- `ionization_adas.py`: локальная функция (theta,N)->(D_ion,E_ion).
- `exitation_adas.py`: локальная функция (theta,N)->E_exc по PLT, имя как в запросе.
- `sources.py`: только локальные источники. Следующие процессы добавляются
  здесь как отдельные вклады, без повторной записи ADAS-нормировки.
- `transport.py`: пробное интегрирование от xi=1 до xi=0 при заданных
  theta,j_t,alpha; локальные R,Q пересчитываются на каждом вызове правой части;
  D задаётся числом либо D(theta), D=0 сохраняет прежнюю версию без CX.
  ionization=(0,0) по умолчанию сохраняет прежние низкоуровневые вызовы без SCD.
  excitation=0 по умолчанию сохраняет низкоуровневые вызовы без PLT.
  Возвращает три невязки, но не объявляет пробу решением краевой задачи.
- `stationary.py`: локальная коррекция трёх неизвестных, повторная коррекция
  с более строгой точностью и независимые интегральные балансы.
- `config.py`, `boundary_fluxes.py`, `inlet.py`, `kinetic_momentum.py`:
  масштабы и условия на входе. Геометрия перенесена в `geometry.py`.
- `profiles.py`: W/W0, q_e, u/u_*, n/n_* и размерные массивы.
- `run_stationary.py`: явный запуск, сохранение отчёта и опционально графика.
- `tests/`: перенесённые тесты коэффициентов и подготовленные проверки модели.

Существенное отличие от старого shooting: a задаётся как независимое пробное
неизвестное. Нет остановки на первом omega=1, предположения omega'<0 или
отсечения lambda*theta*j_t>=1. Это позволяет сохранить постановку при
отрицательном Q_eff, даже если энергетическая кривая немонотонна.

Параметры коррекции — log(theta), log(j_t), logit((alpha-g_min)/(1-g_min)).
Отсутствующий/невалидный IVP не заменяется искусственным штрафом. Локальный
поиск не доказывает полноту, единственность или устойчивость решений.
Трёхпараметрические карты и пакетные сканы доступны через
`scan_stationary.py` и `scan_lambda.py`; см. отдельные инструкции.
По умолчанию нет искусственного верхнего ограничения j_t<=1: ионизация
может дать J(L)>J0. Опциональные j_bounds / --j-min / --j-max задают
только численное окно поиска, не физическую границу. Без ионизации проверка
убывания J сохранена; с ненулевой ионизацией рост J не отбрасывается.

## Конфигурация и данные

`config.json` использует прежние центральные параметры и пример n0=1e14 cm^-3
из старого конфига. Это заданный параметр, не новая оценка/измерение нейтралов.
Постоянный k_cx из конфига больше не используется. Устаревшее поле
k_cx_cm3_per_s в старых JSON принимается, но
игнорируется. В новом примере конфига оно удалено. Конфиг без n0 совместим
с прежним: CX, ионизация и возбуждение выключены (n0=0).
Допускается альтернативный JSON с явными интегральными потоками:

```json
{
  "A_m_cm2": 38.48451000647496,
  "L_cm": 184.5,
  "lambda_sh": 8.0,
  "J0_per_s": 3.9049187683314004e21,
  "M0_dyn": 277465.4221649102,
  "W0_erg_per_s": 7.507643529946354e12
}
```

Режимы задания потоков и центральных параметров не смешиваются.
Для явных потоков по умолчанию G=1, для центральных данных — кинетический вход.
Геометрия по умолчанию A/A_m=500*g^2 на g>=1e-6, **не** точный профиль пробки.
Как прежде доступны JSON `linear_B`, `constant_B`, `quadratic_area_legacy`,
`tabulated_B`. Табличная геометрия не экстраполируется.

Таблицы уже находятся у пользователя в `processes_data/acd12_h.dat` и
`processes_data/prb12_h.dat`. Диапазон: 0.2–10000 eV, 5e7–2e15 cm^-3.
Проверяется локальная электронная плотность вдоль всего слоя. Выход за таблицу
даёт `adas_outside_domain`; экстраполяция/обрезание физических значений запрещены.
Пробный шаг интегратора тоже может выйти за таблицу, поэтому этот статус не
доказывает отсутствие решения. Уменьшение шага/иная численная схема могут
потребоваться при будущей верификации.

Для CX используется processes_data/ccd96_d.dat, 0.2–10000 eV. В этом конкретном
файле коэффициент не зависит от электронной плотности. Его плотностная ось
не заменяет нейтральную n0. Ниже 0.2 eV CCD не экстраполируется.
Ионизация использует processes_data/scd12_h.dat с теми же диапазонами, что
ACD/PRB. Сетка n_e используется локально; это не нейтральная n0.
PLT использует processes_data/plt12_h.dat с теми же диапазонами и с корректной
проверкой заголовка IPRT=1,IGRD=0,Z1=1. Нулевой IGRD не изменяет формулы физики.
Модель считает энергию фотонов уходящей; перенос, запирание и переабсорбция
линий в расширителе не решаются. Это отдельное физическое ограничение PLT-модели.

Нужны Python, NumPy, SciPy; Matplotlib только для графиков. Сырые таблицы имеют
собственные условия использования: не включать их в публичный патч автоматически.
Отчёт сохраняет SHA256 таблиц. Параметр scale умножает **весь** ACD/PRB-канал,
включая тормозное излучение; это не отдельный регулятор только RR.
Отчёт schema_version=5 сохраняет ionization_scale, excitation_scale, D найденного решения,
рождение/убыль частиц и расход энергии в независимых балансах. NPZ содержит
D_cx, D_ion, E_ion и E_exc; последние три записываются массивами профиля
и в гибридном режиме постоянны вдоль слоя. Поле atomic_model различает режимы.
Формат summary.json скана — format_version=2; формат NPZ-куба не менялся.
Старые результаты не переписываются; внешние читатели JSON должны учитывать
новую структуру. В гибриде SHA256 данных содержит только активные ACD/PRB,
а SHA256 кода включает также три файла с прежними коэффициентами.
В полном режиме CCD не загружается при n0=0, SCD — при n0=0 или
--ionization-scale 0, PLT — при n0=0 или --excitation-scale 0.
--scale 0 выключает только ACD/PRB. Независимые бюджеты вызываются через
`balance_checks(state,recombination,ionization,excitation=E_of_state)`:
нельзя незаметно пропустить активную ионизацию или PLT в проверке решения.
Баланс отдельно сохраняет excitation_energy_loss_integral; нет повторного
учёта I*SCD, PRB либо старого L_exc в PLT-канале.

## Команды для будущей проверки (сейчас НЕ выполнялись)

Из корня проекта, явная команда запуска:

```powershell
python -B -m isothermal_model_adas.run_stationary --guess 5 0.8 0.8 --output adas_trial_001
```

Это только пример интерфейса, **не** проверенное приближение и не обещание корня.
Устаревший --cx-mode удалён. --density переопределяет нейтральную n0.
--ionization-scale 1 (по умолчанию) включает ионизацию, 0 выключает её.
--excitation-scale 1 (по умолчанию) включает возбуждение, 0 выключает его.
--density 0 возвращает модель без CX, ионизации и возбуждения. `--plot` сохраняет график лишь если
найдено проверенное решение. С CX больше нет общего вывода об обязательном
отказе в расширяющейся геометрии, но наличие корня всё ещё не установлено.
Существующий каталог результатов не перезаписывается.
