# Изотермическая модель с ACD/PRB

Отдельный пакет, без импортов из `isothermal_cx_model` и `simple_cx_model`.
Старый решатель не изменяется. На этом этапе код **перенесён и проверен только
синтаксически**. Интегрирование, поиск корней и тесты с расчётами не запускались
по просьбе пользователя. Работоспособность численного алгоритма ещё предстоит
проверить; наличие согласованных решений не утверждается.

## Физика и единицы

Стационарная квазинейтральная плазма дейтерия: `n_e=n_i=n`, `u_e=u_i=u`,
`T_e=T_i=T=const`. Вязкости нет. Температура в формулах энергии — в эргах,
в конфиге/ADAS — в eV. Потоки J,M,W интегрированы по магнитной трубке.

Единственный активный атомарный канал — ACD/PRB. Он включает эффективную
рекомбинацию (ACD) и рекомбинационное плюс тормозное излучение (PRB). Поэтому
«только рекомбинация» здесь не означает исключение тормозного излучения из PRB.
CX, возбуждение, ионизация, молекулы и примеси отсутствуют. Плотность нейтралов
не входит в эту версию: концентрация возникающих атомов не эволюционирует.
Используются водородные данные как приближение для дейтерия.

Взяты прежние соглашения об энергии без энергии связи:

    J = A*n*u
    M = A*(m_D*n*u^2 + 2*n*T)
    W = J*(m_D*u^2/2 + 5*T) + A*q_e
    alpha_A(T,n) = ACD(T_eV,n)
    Lambda_B(T,n) = 1e7*PRB(T_eV,n)
    C_eff(T,n) = Lambda_B - I*alpha_A,  I=13.6 eV в эргах

Уравнения:

    J_z = -A*n^2*alpha_A
    M_z = 2*n*T*A_z - A*m_D*u*n^2*alpha_A
    W_z = -A*n^2*[alpha_A*(m_D*u^2/2+3*T/2) + C_eff]
    T_z = 0

Отрицательный C_eff допустим. ACD/PRB интерполируются отдельно в логарифмах,
и лишь затем вычитается I*ACD. Положительная фотонная мощность не равна
непосредственно потере W. Отдельное тормозное излучение не добавляется.

`T=const` означает предел бесконечной теплопроводности, но **не** `q_e=0`:
конечный тепловой поток восстанавливается из W после решения.

## Обезразмеривание и ГУ

    u_* = M0/(m_D*J0), T_* = W0/J0
    n_* = J0/(A_m*u_*), beta = T_*/(m_D*u_*^2)
    j=J/J0, mu=M/M0, omega=W/W0, theta=T/T_*
    g=z/L, alpha=a/L, xi=(g-alpha)/(1-alpha)
    mathcal_A=A/A_m, b=sqrt(8*beta*theta)
    Delta=sqrt(mu^2-b^2*j^2), H=mu+Delta
    N=n/n_*=H/(4*beta*theta*mathcal_A), v=u/u_*=4*beta*theta*j/H
    R(theta,N) = L*n_*/u_* * ACD(theta*T_*,N*n_*)
    Q_eff(theta,N) = L*n_*/(u_* T_*) * C_eff(theta*T_*,N*n_*)

Дозвуковая ветвь: mu>b*j внутри слоя, равенство на стенке. По g:

    j_g = -R*mathcal_A*N^2
    mu_g = -(H/2)*(ln B)_g - R*j*N
    omega_g = -mathcal_A*N^2*[R*(v^2/(2*beta)+1.5*theta)+Q_eff]

Для интегрирования по xi **вся** правая часть умножается на `(1-alpha)`.

    xi=0: j=1, mu=G(alpha), omega=1
    xi=1: mu=b*j_t, omega=lambda_sh*theta*j_t

Неизвестны theta, j_t, alpha. Постоянство theta реализовано параметром,
а не дополнительной ОДУ. G(alpha)=1 при постоянном входном импульсе, либо
прежняя кинетическая модель входа `M_kin(a)/M0` из `inlet.py`.

Кинетическая модель с chi — **унаследованное входное приближение**, а не часть
ADAS. Сохранена без физической переработки. В частности, n_m=n_c/2, T_m=T_c,
W0=chi_E*J0*T_c. Не следует заменять это умножением плотности на B_m/B_c.

## Важное ограничение задачи только с рекомбинацией

Пусть F=mu-b*j. На стенке:

    F_g(1)/j_t = (b/2)*(ln A)_g(1) + R_t*N_t

Для дозвукового слоя слева от стенки необходима `F_g(1)<=0`. При расширении
на стенке и ненулевой рекомбинации правая часть положительна: такой дозвуковой
подход к условию Бома **невозможен в данной усечённой модели**.
Решатель возвращает `inadmissible_wall`. Это локальный строгий аргумент,
не следствие неудачного поиска корня. При нулевой первой производной
`critical_wall_unresolved`: вырожденный случай ещё не исследуется.

Геометрию нельзя менять на сужающуюся ради получения «решения для ГДЛ».
Сужающаяся геометрия в подготовленных тестах — исключительно контроль кода.
После добавления других процессов условие допустимости нужно вывести заново.

## Файлы и стратегия

- `recombination_adas.py`: перенесённый пользователем reader/интерполятор;
  `make_adas_coefficients(p,scale=1)` возвращает функцию `(theta,N)->(R,Q_eff)`.
  Историческая пометка standalone в его docstring относится к старому пакету.
- `sources.py`: только локальные источники. Следующие процессы добавляются
  здесь как отдельные вклады, без повторной записи ADAS-нормировки.
- `transport.py`: пробное интегрирование от xi=1 до xi=0 при заданных
  theta,j_t,alpha; локальные R,Q пересчитываются на каждом вызове правой части.
  Возвращает три невязки, но не объявляет пробу решением краевой задачи.
- `stationary.py`: локальная коррекция трёх неизвестных, повторная коррекция
  с более строгой точностью и независимые интегральные балансы.
- `config.py`, `boundary_fluxes.py`, `inlet.py`, `kinetic_momentum.py`:
  масштабы и условия на входе. Геометрия перенесена в `geometry.py`.
- `profiles.py`: W/W0, q_e, u/u_*, n/n_* и размерные массивы.
- `run_stationary.py`: явный запуск, сохранение отчёта и опционально графика.
- `tests/`: перенесённые тесты коэффициентов и подготовленные проверки модели.

Существенное отличие от старого shooting: a задаётся как независимое пробное
неизвестное. Нет остановки на первом omega=1, предположения omega'<0 или
отсечения lambda*theta*j_t>=1. Это позволяет сохранить постановку при
отрицательном Q_eff, даже если энергетическая кривая немонотонна.

Параметры коррекции — log(theta), log(j_t), logit((alpha-g_min)/(1-g_min)).
Отсутствующий/невалидный IVP не заменяется искусственным штрафом. Локальный
поиск не доказывает полноту, единственность или устойчивость решений.
Двумерные карты и массовые сканы пока не переносились.

## Конфигурация и данные

`config.json` использует прежние центральные параметры, но больше не требует
n0 или k_cx. Допускается альтернативный JSON с явными интегральными потоками:

```json
{
  "A_m_cm2": 38.48451000647496,
  "L_cm": 184.5,
  "lambda_sh": 8.0,
  "J0_per_s": 3.9049187683314004e21,
  "M0_dyn": 277465.4221649102,
  "W0_erg_per_s": 7.507643529946354e12
}
```

Режимы задания потоков и центральных параметров не смешиваются.
Для явных потоков по умолчанию G=1, для центральных данных — кинетический вход.
Геометрия по умолчанию A/A_m=500*g^2 на g>=1e-6, **не** точный профиль пробки.
Как прежде доступны JSON `linear_B`, `constant_B`, `quadratic_area_legacy`,
`tabulated_B`. Табличная геометрия не экстраполируется.

Таблицы уже находятся у пользователя в `processes_data/acd12_h.dat` и
`processes_data/prb12_h.dat`. Диапазон: 0.2–10000 eV, 5e7–2e15 cm^-3.
Проверяется локальная электронная плотность вдоль всего слоя. Выход за таблицу
даёт `adas_outside_domain`; экстраполяция/обрезание физических значений запрещены.
Пробный шаг интегратора тоже может выйти за таблицу, поэтому этот статус не
доказывает отсутствие решения. Уменьшение шага/иная численная схема могут
потребоваться при будущей верификации.

Нужны Python, NumPy, SciPy; Matplotlib только для графиков. Сырые таблицы имеют
собственные условия использования: не включать их в публичный патч автоматически.
Отчёт сохраняет SHA256 таблиц. Параметр scale умножает **весь** ACD/PRB-канал,
включая тормозное излучение; это не отдельный регулятор только RR.

## Команды для будущей проверки (сейчас НЕ выполнялись)

Из корня проекта, явная команда запуска:

```powershell
python -B -m isothermal_model_adas.run_stationary --guess 5 0.8 0.8 --output adas_trial_001
```

Это только пример интерфейса, **не** проверенное приближение и не обещание корня.
Для стандартной расширяющейся геометрии ожидается диагностический отказ,
описанный выше. `--plot` сохраняет график лишь если найдено проверенное решение.
Существующий каталог результатов не перезаписывается.

Позднее можно отдельно запустить подготовленные тесты:

```powershell
python -B -m unittest discover -s isothermal_model_adas/tests -v
```

Первым следующим этапом верификации должны быть контрольная задача с известным
решением, сходимость по шагу/точности и проверка нового трёхпараметрического
корректора. Только затем следует интерпретировать физические ветви.
