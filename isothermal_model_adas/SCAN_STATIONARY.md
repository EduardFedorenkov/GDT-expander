# Автоматический стационарный поиск ADAS

`scan_stationary.py` выполняет цепочку:

```text
config + геометрия + ADAS -> карта (theta,j_t,alpha) -> выбранные старты
    -> существующий solve_stationary() -> проверенные корни и профили
```

Уравнения и физические замыкания не меняются. В `stationary.py` добавлена
только обёртка `find_stationary_solutions()` для многократного вызова
существующего корректора и удаления дубликатов. `--guess` не обязателен.

## Первый запуск

Все команды — из корня проекта. Сначала проверить настройки без
интегрирования плазмы и без создания файлов:

```powershell
python -B -m isothermal_model_adas.scan_stationary --dry-run --no-show
```

По умолчанию: 16 температур, 16 значений j_t, 7 значений alpha — **1792
пробных интегрирования**. При уточнении корней потребуются дополнительные
интегрирования; их число заранее неизвестно. dry-run читает конфиг и
проверяет активные таблицы, но не решает уравнения переноса.

Посмотреть только карту на редкой сетке:

```powershell
python -B -m isothermal_model_adas.scan_stationary --temperature-count 8 --j-count 8 --alpha-count 5 --alpha-slice 2 --map-only --no-show --output adas_map_001
```

Карта и автоматическое уточнение:

```powershell
python -B -m isothermal_model_adas.scan_stationary --temperature-count 8 --j-count 8 --alpha-count 5 --max-starts 12 --no-show --output adas_scan_001
```

Это примеры интерфейса, не проверенные настройки плазменного эксперимента
и не обещание корней. Физические сканы при разработке не запускались.
Редкая сетка может пропустить корни; нужны её сгущение и расширение области.

## Основные флаги

- `--config PATH`: по умолчанию новый `isothermal_model_adas/config.json`.
- `--density N0`, `--lambda-sh VALUE`: переопределяют нейтральную плотность
  в см^-3 и параметр стенки, не редактируя исходный JSON.
- `--temperature-min/max/count`: логарифмическая сетка в eV, по умолчанию
  .2..100, 16 точек. theta вычисляется через T_star. Сетка должна быть
  внутри температурного диапазона активных таблиц, без экстраполяции.
- `--j-min/max/count`: сетка J(L)/J0, по умолчанию 1e-6..10, 16 точек.
  `--j-grid log|linear`, по умолчанию log. Значения j_t>1 допустимы.
- `--alpha-min/max/count`: линейная сетка a/L, по умолчанию .05...995,
  7 точек. Требуется g_min < alpha_min < alpha_max < 1.
- `--geometry PATH`: существующий JSON-формат B(z); либо `--K VALUE`
  для A/A_m=K*(z/L)^2. Без обоих параметров K=500.
- `--inlet-momentum auto|kinetic|constant`: auto выбирает kinetic при
  центральных параметрах и constant при явных J0,M0,W0, как run_stationary.py.
- Перезарядка всегда использует CCD(T); флага выбора коэффициента нет.
- `--rr-scale` (синоним `--scale`): общий множитель всего канала ACD/PRB,
  включая тормозное излучение PRB, не только радиационной рекомбинации.
- `--ionization-scale`, `--excitation-scale`: множители SCD и PLT.
  Все scale по умолчанию 1; диапазон 0..1. Отключённые таблицы не читаются.
- `--guess T_EV J_TARGET ALPHA`: дополнительная стартовая тройка внутри
  сеточных диапазонов; можно повторять. Точные повторения стартов удаляются.
- `--max-starts`, `--separation`: автоматические старты; см. RESIDUAL_MAP.md.
- `--iterations`, `--points`: итерации каждого уточнения и точки итоговой
  независимой проверки/сохранения (минимум 100).
- `--map-points`: точки профиля при каждом пробном расчёте карты.
- `--rtol`, `--atol`, `--max-step`: точность и шаг интегратора; max-step в xi.
- `--residual-tol`, `--balance-tol`: допуски невязок и независимых бюджетов.
- `--dedup-tol`: объединение корней по log(theta), log(j_t) и абсолютной alpha.
- `--no-show`: сохранить PNG без интерактивных окон; `--no-plot`: без PNG.
- `--alpha-slice INDEX`: дополнительный срез, индекс с нуля.
- `--j-axis log|linear|loss`: ось карты; loss отображает знаковую 1-j_t.
- `--output PATH`: новая или пустая папка; прежние результаты не затираются.

## Границы уточнения и смысл результатов

Корректор удовлетворяет трём условиям: j(a)=1, mu(a)=G(alpha), omega(a)=1.
Температура ограничена заданным диапазоном карты. Для j_t используется
прежний численный нижний предел 1e-12, без верхнего ограничения картой или
единицей. Для alpha доступен весь открытый интервал геометрии (g_min,1).
Если корень вышел за сетку j_t или alpha, это отмечается в отчёте.

Корни объединяются только при близости всех трёх неизвестных; различные
alpha не теряются из-за одинаковой температуры. Близкие корни внутри
dedup-tol могут объединяться, но координаты и история каждой попытки
остаются в диагностике. root_001 и т. п. — ID обнаружения, не физические ветви.

Q_eff может быть отрицательным, omega немонотонной, j_t больше единицы.
ADAS-коэффициенты продолжают зависеть от локальной плотности. CCD(T)
фиксирован на каждой изотермической попытке. Дополнительное тормозное
излучение поверх PRB не добавляется. Корень экспортируется только после
проверки граничных условий и независимых интегральных балансов.

## Результаты и прерывание

- `summary.json`: параметры, сетки, старты, попытки, невязки, корни и бюджеты.
- `source_config.json`, `geometry.json`: снимки исходных входных файлов;
  CLI-переопределения отражены в `summary.json -> parameters`.
- `residuals.npz`: полный куб (alpha,j,theta), чтение с allow_pickle=False.
- `residuals.png`: проекция полной нормы невязок по дискретной alpha.
- `alpha_slice_NNN.png`: срез при запросе.
- `root_NNN_profiles.npz`: размерные и безразмерные профили, локальные
  коэффициенты, theta, T_eV, alpha, j_target.
- `root_NNN_profiles.png`: W/W0, q_e, u/u_star, n/n_star.

В provenance сохранены SHA256 активных таблиц, исходного конфига и исходников
пакета, версии Python/NumPy/SciPy. Сырые .dat не копируются. Формат отчёта:
model=isothermal_adas, kind=stationary_scan_3d, format_version=2. Поля выбора
коэффициента перезарядки больше нет, используется только CCD(T). Формат
NPZ-куба остаётся прежним; сохранённые ранее отчёты не переписываются. Это не старый
двухпараметрический формат Case-A.

Карта сохраняется **до уточнения**. Отчёт атомарно обновляется после каждой
завершённой попытки, новые корни сразу получают профили. При обычном Ctrl+C
stage=interrupted; уже построенная карта и сохранённые результаты остаются.
Если прервать само построение карты, полного куба ещё не будет. При аварийном
закрытии процесса отчёт может остаться на последней активной стадии — это
не завершённый поиск. Автоматического resume пока нет; новый запуск — в новую папку.

Стадии: mapping, map_complete, refining, refinement_complete, map_only,
interrupted, failed. Ошибка таблиц/коэффициентов не трактуется как «0 корней».

Коды завершения: 0 — есть проверенные корни либо выполнен map-only/dry-run;
1 — конечный поиск завершён без найденных корней; 2 — обработанная ошибка;
130 — прерывание. Непредвиденное исключение может дать другой ненулевой код:
для будущих пакетных сканов нужно проверять стадию и формат отчёта, не только код.

## Тесты без физических сканов

```powershell
python -B -m unittest isothermal_model_adas.tests.test_scan_stationary -v
```

Проверены работа настоящего корректора на искусственных невязках с известным
корнем, объединение дубликатов, передача процессов, режимы CLI, сохранение,
прерывание и отрисовка. Физическое интегрирование в этих тестах заменено
тестовыми функциями. Наличие плазменных решений и сходимость по точности и
сетке ещё предстоит исследовать отдельно.
