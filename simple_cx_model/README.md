# Simple CX model

Первая версия одномерной модели с перезарядкой разделена на небольшие модули по
их ответственности:

- `constants.py` — физические константы;
- `boundary_fluxes.py` — оценка потоков через одну магнитную пробку;
- `config.py` — чтение JSON, вычисление потоков и характерных масштабов;
- `solver.py` — поиск `theta`, `alpha` и проверка существования решения;
- `profiles.py` — расчёт пространственных профилей;
- `plotting.py` — визуализация результатов и области решений;
- `run_cx.py` — сценарий запуска модели;
- `cx_functions.py` — совместимость со старыми импортами.

Новые физические эффекты лучше добавлять в вычислительные модули, не связывая
их с построением графиков или чтением конфигурации. Публичные функции пакета
экспортируются из `__init__.py`.

Запуск из корня проекта:

```powershell
python -m simple_cx_model.run_cx
```

Для другого файла конфигурации передайте его путь первым аргументом:

```powershell
python -m simple_cx_model.run_cx path/to/config.json
```

## Входные параметры источника

В JSON задаются `A_m_cm2` (площадь в пробке, см^2), `n_c_cm3` (центральная
плотность, см^-3), `T_c_eV` (центральная температура, eV) и безразмерный
`chi_E` (полная энергия уходящей электрон-ионной пары в единицах T_c).
Поля `k_cx_cm3_per_s`, `lambda_sh`, `L_cm`, `n0_cm3` сохраняются.
`n0_cm3` означает плотность нейтрального газа, а не центральной плазмы.
`m_D_g` необязателен; по умолчанию используется масса дейтерия.

Принята модель: ионное распределение в пробке является половинкой полного
Максвелла, нормированного на n_c. Поэтому физическая плотность в пробке
n_m = n_c/2, а температурный параметр T_m = T_c. Это отдельное приближение,
а не следствие изотермичности или отношения магнитных полей.
Для электронов принимается p_parallel_e = n_m*T_m; направленная электронная
инерция не учитывается.

Парсер автоматически вычисляет потоки через одну пробку:

- J0 = A_m*n_m*sqrt(2*T_m/(pi*m_D)), ионов (пар) в секунду;
- M0 = 2*A_m*n_m*T_m, dyn, ионный вклад плюс электронное давление;
- W0 = chi_E*J0*T_m, erg/s, полный ионно-электронный поток энергии.

В этих формулах T_m переводится из eV в erg. Дополнительный множитель 2
в W0 не нужен. `chi_E` не является пристеночным коэффициентом `lambda_sh`.

`J0_per_s`, `M0_dyn`, `W0_erg_per_s`, `A0_cm2` больше не задаются в JSON:
парсер отклоняет их, чтобы исключить неоднозначность входных данных.
В возвращаемом словаре эти ключи сохранены для существующих решателей;
`A0_cm2` является псевдонимом `A_m_cm2`. Также доступны `n_m_cm3`, `T_m_eV`
и исходные параметры источника.

Включённый `cx_config.json` содержит пример n_c = 1e13 см^-3, T_c = 100 eV,
chi_E = 8. Эти значения не являются восстановленными экспериментальными
данными и дают другие потоки, чем прежние вручную заданные J0, M0, W0.
Подставьте параметры своего режима.

Обновление конфигурации не реализует согласование M_kin(a) на входе
гидродинамической области и не изменяет граничные условия решателей.
