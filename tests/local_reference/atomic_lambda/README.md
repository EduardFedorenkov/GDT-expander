# Локальный референс полного атомарного скана

Источник: сохранённые результаты C:\Projects\1D-plasma-expander-model\atomic_lambda_test.
CSV, конфиг, геометрия и manifest скопированы без изменения содержимого.
Это локальный численный референс, не экспериментальные данные.

Исходный запуск (нынешнее имя команды):

```powershell
python -B -m isothermal_cx_model.scan_lambda --lambdas 7 8 9 10 --densities 1e12 5e12 1e13 5e13 1e14 5e14 1e15 5e15 1e16 --no-show --output atomic_lambda_test_1
```

Полные настройки и масштабы находятся в manifest.json. Изотермический
атомарный набор: CX(T,0), возбуждение, Case-A RR, прямая ионизация;
все множители процессов 1, кинетический вход, A/Am=500*(z/L)^2.
Сетка: 45 температур, 49 фактических точек j_t; 36 физических пар.
Найдено 64 корня: по 2 при каждой n0 выше 1e12, по 0 при n0=1e12.
Нулевой результат конечного поиска не является доказательством несуществования.

Сравнить новый расчёт:

```powershell
python -B tests/compare_local_reference.py atomic_lambda_test_1 --json-output reference_comparison.json
```

Сопоставление выполняется по lambda и n0, затем по T, a и j_t,
независимо от локальных ID и порядка строк. Требуется точное совпадение
числа корней и настроек физики. Допуски физических величин: rtol=1e-7,
с явно заданными абсолютными порогами для малых значений; невязки
сравниваются по абсолютной погрешности, не по относительной к нулю.
Различия диагностических счётчиков выводятся отдельно, не скрываются.

Старые отчёты и NPZ профилей отдельных пар отсутствуют: сохранённые пути
case_report — историческая информация, для чтения референса они не нужны.
По этим CSV нельзя подтвердить совпадение пространственных профилей.
Изменение code_sha256 ожидается при рефакторинге и не считается изменением
физических параметров. Защита resume в самом решателе не ослабляется.

Этот референс не обновляется автоматически при несовпадении. При намеренном
изменении физической модели создавайте отдельный новый референс и явно
фиксируйте причину, не перезаписывая этот набор.
